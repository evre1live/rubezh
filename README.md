# РУБЕЖ — оборона 1987

Tower defence в духе стратегий конца 90-х. Ташкент, 1987 год: Орден Третьего Глаза идёт волнами от пси-маяка к штабу у телебашни. Одиночная игра и кооператив на двоих.

## Запуск

```bash
npm install
npm start            # http://localhost:8080
```

Одиночная партия считается прямо в браузере. Для кооператива нужен этот сервер: он держит комнаты и считает партию.

## Хостинг на Render

В репозитории есть `render.yaml`: в Render выберите **New → Blueprint** и укажите репозиторий. Либо вручную: **Web Service**, Node, `npm install`, `npm start`, проверка здоровья `/health`, бесплатный тариф. WebSocket на Render работает без настроек.

## Устройство

- `sim/` — правила и симуляция без графики, общие для сервера и браузера. `data.js` — карта, башни, враги, волны, баланс; `game.js` — партия: 20 тиков в секунду, команды игроков, снимки состояния.
- `server/server.js` — раздача файлов и комнаты по коду из 4 символов. Команды игроков проверяются на сервере, снимки уходят 10 раз в секунду. После обрыва связи место игрока держится 3 минуты, вход обратно — по токену из браузера.
- `client/` — three.js r160, изометрическая камера, процедурные модели (`models.js`), сцена и эффекты (`render.js`), звук WebAudio без файлов (`audio.js`), интерфейс (`main.js`, `style.css`). Шрифты лежат в `client/fonts` (Russo One, Oswald, PT Mono).
- `tools/build.js` — одиночная версия одним файлом: `npm run build` → `dist/rubezh-solo.html`.

## Проверки

- `npm test` — партии ботов без графики: проверка баланса для 1 и 2 игроков.
- `test/play.cjs`, `test/coop.cjs`, `test/scenes.cjs` — партии через интерфейс в Playwright (сервер запускать с `ALLOW_SPEED=1`, чтобы работал параметр `?speed=`).

## Управление

Иконка справа или клавиши 1–4 — строить; когда готово, нажмите на клетку. Правая кнопка — отложить или отменить. Колесо — приближение, правая кнопка с движением или WASD — двигать карту. Пробел — вызвать волну раньше (с доплатой), Q — метка для союзника, Esc — меню.
